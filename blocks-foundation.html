The four blocks, and what they turn into

These are the four you picked out of blocks-lab-picks.html — 1, 3, 7 and 8 — each one first exactly as it was, then three more blocks built in the same style. Nothing else. The point is to feel out each style with real hardware-store data in it before we decide anything.

Every block obeys the same eight rules the four originals already obeyed: one number per card and it is the biggest thing; the comparison basis is printed, never hidden; no data is an em dash rather than a red -100%; colour is a chip or a single word; label left, number right; every bar and ring draws its own track; furniture recedes; and a second stacked line only when it is a different kind of fact.

Tweak it here. Nothing ports into styles.css until you say so.
